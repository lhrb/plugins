# Audio plugin profiling system

`analyse/` aims to provide scientific profiling of audio plugins through standardized measurements and clear, inspectable plots.

It answers three questions:

1. What exactly changes in the audio signal?
2. Which measurable characteristics explain the plugin's sound?
3. Which plugins produce similar results, and when should I choose one over another?

## Intended capabilities

- Reliable CLAP and VST3 hosting.
- Automated frequency-response measurements.
- Harmonic analysis across frequency and input level.
- Transient and dynamics analysis.
- A database of results with standardized measurement conditions and identifiable plugin settings.
- Plugin-to-plugin comparisons through plots and measured differences.

Plots make the stimulus, signal changes, measurement conditions, and limitations understandable.
Results describe behavior under tested conditions, not hidden algorithms, universal perceptual equivalence, or subjective quality.
